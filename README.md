# 📝 Todo List App | اپلیکیشن لیست کارها

یک اپلیکیشن مدیریت کارهای روزانه، ساده و زیبا با استفاده از HTML، CSS و Vanilla JavaScript (بدون هیچ کتابخانه‌ای). اطلاعات به صورت خودکار در `LocalStorage` مرورگر ذخیره می‌شوند.

### ✨ ویژگی‌ها (Features)
*   **افزودن و حذف:** اضافه کردن تسک با کلید Enter یا دکمه، حذف تکی و گروهی.
*   **ویرایش درجا:** تغییر متن تسک‌ها فقط با یک کلیک (دکمه ✎).
*   **تغییر وضعیت:** علامت‌گذاری کارهای انجام‌شده با چک‌باکس.
*   **شمارنده هوشمند:** نمایش تعداد تسک‌های انجام‌شده.
*   **طراحی راست‌چین (RTL):** رابط کاربری کاملاً فارسی و مینیمال.

# 📝 Todo List App

A simple and clean daily task manager built with pure **HTML**, **CSS**, and **Vanilla JavaScript**. All data is automatically saved in the browser's `LocalStorage`.

### ✨ Features
*   **Add & Delete:** Add tasks via Enter key or button; delete single or all tasks.
*   **Inline Editing:** Edit task titles directly by clicking the ✎ button.
*   **Toggle Status:** Mark tasks as completed with a checkbox.
*   **Live Counter:** Shows the ratio of completed tasks.
*   **RTL Design:** Fully responsive Right-to-Left UI.
